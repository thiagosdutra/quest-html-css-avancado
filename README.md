# Quest HTML + CSS avançado - Devquest:

O presente projeto foi desenvolvido com o objetivo de aplicar, na prática, os conhecimentos adquiridos durante as aulas de HTML e CSS avançado. A estrutura da página foi pensada para ser simples, funcional e bem organizada.

A página é composta por três seções principais:

1. Header: onde foi inserido o logotipo do site, representando a identidade visual da página de forma clara e objetiva.

2. Main: dividido em duas partes principais: uma imagem ilustrativa e uma seção de texto com título, parágrafo e um botão com efeito visual.

3. Footer: contendo ícones de redes sociais estilizados, com efeitos visuais aplicados para realçar a interação com o usuário.


Durante o desenvolvimento, foi aplicado o uso do display: flex como principal técnica de organização de layout, permitindo controle preciso sobre o posicionamento e a adaptação dos elementos em diferentes tamanhos de tela. O resultado final reflete a consolidação prática dos conteúdos estudados, demonstrando domínio na construção de páginas web, modernas e visualmente equilibradas apenas com HTML e CSS.
